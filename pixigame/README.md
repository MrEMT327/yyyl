# 少女航线

## 正常流程与开发按钮

默认启动和 `npm run build` 均为正常游戏：资源正常扣除，内容按进度解锁，不再自动补满或全开，也不临时开放未获得的驾驶员。原有角色立绘与技能实现保留。

主界面右侧“开发”打开独立工具：每次领取金币 100,000 或钻石 1,000，直接存入正式材料钱包，后续消费和重载不会补满。面板内“一键清档，重建新手档”需要再次确认，随后删除当前网址的 `thunder-` 游戏存档及旧档备份、清除试玩会话并刷新。不同端口、设备的档案互相独立；不会调用 `localStorage.clear()`。战斗或广告处理中不可清档。

发布更新不会自动删除旧档；已有开发资源/全开备份仍按原有恢复逻辑退出开发状态。要从真正的新手档开始，请手动使用开发面板的清档按钮。`build:economy` 仅保留为独立端口的验证命令，不再代表另一套游戏规则。

## 历史规则（仅旧版Boss开发测试入口保留）

- 12 条武器路线：基础白弹、赤猎制导、蓝涡螺旋、棱角折射、重力弹球、蜂群僚机、寒霜冰弹、天穹集束炮、万剑归宗、双星锁链、灼日锁定与量子裁决。
- 新弹道分别提供空爆子母弹、蓄势归宗剑阵、双球动态伤害锁链和持续锁定灼烧激光。
- 除量子裁决外，每条路线都有独立 Buff（击退、眩晕、易伤、冻结、束缚或灼烧），并随同系升级同步增强。
- 前 8 次技能投入的三选一固定保底一张强化，其余卡位优先提供不同的新技能；之后恢复混合随机。同一技能等级越高，再次出现的权重越低。
- 各路线有 5–6 段强化链，满足前置条件后可出现专属终极联动。

## 局域网试玩

```bash
npm run lan
```

该命令会先生成生产构建，再将试玩页面固定发布到 `4173` 端口，并监听所有局域网网卡。终端会显示 `Network` 地址；把它发给处于同一 Wi-Fi 或同一有线网络的同事即可。

如果同事无法访问：

1. 确认双方在同一个局域网，并关闭访客 Wi-Fi 的设备隔离。
2. 保持运行 `npm run lan` 的终端窗口不要关闭。
3. macOS 弹出网络访问提示时，允许 Node 接受传入连接。
4. 检查系统防火墙是否放行 TCP `4173` 端口。
